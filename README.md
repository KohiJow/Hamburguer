# Hamburguer

App mobile de hamburgueria em React Native com Expo, escrito em TypeScript.

## O que tem

- Navegacao por arquivos com expo-router
- Tipografia Inter via Google Fonts
- Carrinho e preferencias guardados com AsyncStorage
- Icones do pacote Expo Vector Icons

## Rodando

```bash
npm install
npx expo start
```

Abra no Expo Go pelo QR code, ou rode num emulador.
